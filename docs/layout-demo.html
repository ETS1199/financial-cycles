Country layout options

Layouts← Back to the board

Same 12 countries in four layouts, on live data — the hottest five plus a spread of calm ones, so you can judge rhythm and density. Everything is monochrome; the only ink weights are text tokens and one data ink.

Option A

Current — value tile

What the board ships today: name, index, both gaps, quarter. Fastest to scan for the index number; the gap figures are there but read as fine print.

Option B

Value tile + history strip

Adds a 24-quarter mini history under the numbers — dark cells are quarters with a signal over its threshold. Turns each tile into "where it is and where it has been", and previews the strip on the detail page. Costs about 30px of tile height.

Option C

Value tile + threshold meters

Each gap becomes a meter drawn on a shared scale: the tick is that signal's threshold, the bar runs from zero to the current gap. Both meters use "multiples of the threshold", so equity and output are directly comparable and you can see how close a calm country is to its bar — the thing the raw percentages hide.

Option D

Table

One row per country. The densest and the easiest to compare down a column — with 30 markets, a table is the classic answer. Sleek in a spreadsheet way rather than a dashboard way, and it loses the card rhythm.
