Methodology, beginning to end

Every number on the board is produced by the same pipeline, run country by country. It is a live-data replication of the Advanced-Market track of Chen & Svirydzenka (2021). The steps below outline the process.

Assemble the series

Each economy contributes three time series: seasonally-adjusted real GDP, share-price index, and CPI. Share prices are deflated by CPI to real equity prices, and monthly CPI is averaged to quarters. We use the natural logarithm of each target series so that their multiplicative growth (rates) becomes additive, as the Christiano–Fitzgerald filter is a linear operator, and it operates on those additive values. Sources differ by country (FRED, Eurostat, ONS, ABS, Statistics Canada, IMF IFS... see References).

Where the bands come from

The filter has to be told which cycle lengths to keep, and that number was determined using the Harding–Pagan turning-point algorithm. The paper dates every peak and trough in every series across all 34 advanced markets, with short blips censored out so a two-quarter wobble cannot count as a cycle. The distance between those turning points gives each cycle's length.

The group averages of those lengths are the paper's Table 1 (mean cycle length and its standard deviation, by series, for the advanced-market group). The paper states that the filter's pass-band is set to that average ± 2 standard deviations, and reports the resulting band directly in Table 2, in quarters: equity 8–22, GDP 3–51. The bands used on this page are taken directly from that table. One band is set for the whole advanced-market group, so every market here and in the paper are filtered identically.

How the trend is found using the band-pass filter

Every gap on this page comes from the Christiano–Fitzgerald band-pass filter. Each series is first made real (deflated by CPI) and logged; the filter then splits that log series in two. The cyclical swing is what the band passes through, that is the movement whose period falls inside the band above. Everything else is the slow trend, the drift too slow to fit in the band, along with the wobble too fast for it. That swing, ×100, is the gap, which read as roughly a percentage deviation from trend. Here is exactly what it computes.

1. The pass-band. Choose the band of cycle lengths to keep, periods between pl (shortest) and pu (longest), in quarters and convert them to angular frequencies:

a = 2πpu b = 2πpl

Bands used here: equity 8–22 quarters, output 3–51 quarters. As previously stated.

2. The weights. The filter is a set of weights applied to neighbouring quarters:

B0 = b − aπ Bj = sin(jb) − sin(ja)πj ,j ≥ 1

3. Two-sided and one-sided. The filter comes in two versions, and the difference between them is whether future data exists yet. With hindsight (two-sided), the cycle at quarter t is a weighted sum of the data on both sides of it. The ideal measurement, since a trend is best placed through a point when you can see the series on either side:

ŷt = B0xt + ΣT−1−tj=1 Bjxt+j + B̃T−txT + Σt−2j=1 Bjxt−j + B̃t−1x1

However in real time that future data does not exist. The one-sided version is the same filter with the forward terms dropped at the latest quarter T.So the weight on the current observation halves and the end-weight takes up the remainder:

ŷT = 12B0xT + ΣT−2j=1 BjxT−j + B̃T−1x1

The end-weights B^~ in both formulas are what stands in for the data past the edge of the sample. Each one is the sum of every weight that would have fallen beyond that edge, applied in a single lump to the boundary observation. Since the full set of weights sums to zero, that leftover tail can be written using only the weights you have:

B̃k = −12B0 − Σk−1j=1 Bj

Where k is the boundary observation's distance in quarters. Christiano & Fitzgerald set this out in footnote 3 on page 2 of The Band Pass Filter, with the one-sided case B_{T-1} in footnote 4 on page 3.

Which version is used where. Every reading on this site, the board, the charts, and each cell of the quarter-by-quarter strip is the one-sided read for its quarter, the value an observer would have computed at the time, using only the data that existed then.

Because each cell is computed from data up to its quarter and nothing later, the cells never change. A new quarter of data adds a cell and leaves the rest untouched. What changes is not the reading but what we later learn the quarter was. Leaning on the end-weight instead of real future data pulls a real-time reading toward zero, so a building boom reads milder at the time than hindsight shows and it can point the wrong way. Canada's equity gap for 2024Q3 read +0.5% on the one-sided filter, the value available when that quarter was current. Run the two-sided filter over that same quarter, using the surrounding data that exists today, and it reads −4.9% instead.

4. Drift, then the gap. The weights above assume the series has no drift, so the drift has to come out before any of it runs. Call the raw log series wt. Its average growth per quarter, μ̂, is read off the two end points, and one more μ̂ is removed at each step along the sample. What is left is the drift-adjusted series xt, the series every formula above actually filters.

μ̂ = wT − w1T − 1 xt = wt − (t − 1)μ̂ gapt = 100 × ŷt

Behind that estimate is an assumption that the raw series is a random walk with drift, each quarter's value being the last one plus a fixed step μ plus a zero-mean disturbance ut.

wt = μ + wt−1 + ut

Because the series is in logs, the straight line it describes is steady growth, so removing it leaves a series that ends at the level it began. This is Christiano & Fitzgerald's own drift adjustment, set out in footnote 7 on page 4 of The Band Pass Filter.

Flag and aggregate

Each quarter, every gap is compared with its threshold from the paper's Table 5 with equity +6.7%, output +1.3%, both in percent deviation from trend. An indicator is 1 when its actual value is above the expected. If not it is 0, and the Overheating Index is the weighted sum:

Overheating index (paper eq. 8, AM weights)
OI = 0.497 · I(equity) + 0.503 · I(output)

The weights are the paper's published normalized weights, derived from each indicator's crisis-signalling reliability. Being near-equal, the index in practice counts how many signals are on.

Limits of the calibration

Everything upstream of the live data such as cycle durations, filter bands, thresholds and weights were determined by the paper's 1960–2014 sample and is held fixed. That freeze keeps every market comparable against the same crisis-calibrated bar, but it ages its two layers age differently:

  • The bands can drift out of date. The filter only extracts swings inside the band; if advanced-market cycles have lengthened since 2014, a boom building more slowly than 22 quarters would be absorbed into "trend" and the equity gap would understate it. A bias toward missed warnings rather than false alarms.
  • The thresholds cannot be re-checked. The +6.7% / +1.3% bars minimize missed crises versus false alarms over a small set of historical episodes with no new advanced-market systemic banking crisis to test against. Verified through 2025: the crisis database (see References) adds no new advanced-market episodes.

Treat a threshold crossing as a prompt to investigate the economy further and weigh persistent deviations more heavily than a single reading.
